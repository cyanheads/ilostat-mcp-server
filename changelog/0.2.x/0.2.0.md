# 0.2.0 — 2026-10-15

## Added

- **`ilostat_query_indicator` `remaining_dataset_ids`** ([#20](https://github.com/cyanheads/ilostat-mcp-server/issues/20)). `dataset_ids` accepts up to 100 IDs, all validated up front; the first 3 distinct datasets are queried and the rest return in `remaining_dataset_ids` with a notice.
- **`ilostat_compare_geographies` baseline provenance** ([#17](https://github.com/cyanheads/ilostat-mcp-server/issues/17)). `change` carries the baseline's source, basis, status, and notes plus `source_changed`, `basis_changed`, and `break_in_series`; the notice counts changes that are not like-for-like. `break_in_series` is null when only the two endpoints were read.
- **`ilostat_describe_indicator` `related_total`** ([#16](https://github.com/cyanheads/ilostat-mcp-server/issues/16)) counts every other indicator sharing the measure beside the first 20 `related_datasets`, with `truncated`/`shown`/`cap` enrichment; `ilostat_search_indicators` gains a `measure` filter that lists them.
- **`ilostat_dataframe_query` `applied_limits`** (`row_limit`, `preview`, `preview_chars`) on both surfaces ([#19](https://github.com/cyanheads/ilostat-mcp-server/issues/19)).
- **`ilostat_dataframe_describe` unit fields** `unit_measure`, `unit_type`, `unit_type_label`, `unit_multiplier`, and `unit_multiplier_label` per dataset, inherited by `register_as` dataframes; values are never rescaled ([#18](https://github.com/cyanheads/ilostat-mcp-server/issues/18)).

## Changed

- **`latest_only` and the country profile** keep each series' own latest period instead of the latest year per area, so a youth series ending a year early is no longer dropped ([#12](https://github.com/cyanheads/ilostat-mcp-server/issues/12)). A history too large to read in one call falls back to `latestyear`, reported in `applied_filters.latest_mode` and the notice.
- **`ilostat_dataframe_query` previews stop at `ILOSTAT_PREVIEW_CHARS`**, cutting between whole rows with guidance for the remainder; a lone oversized row is withheld with a `substr()` part size that fits ([#14](https://github.com/cyanheads/ilostat-mcp-server/issues/14)).
- **`row_limit` and `preview`** past the per-call cap (10,000, or `CANVAS_DEFAULT_ROW_LIMIT` when lower) are applied as the cap with a notice; `row_limit` still rejects above 1,000,000 and `preview` has no maximum ([#19](https://github.com/cyanheads/ilostat-mcp-server/issues/19)).
- **`limit` past the page cap** on `ilostat_search_indicators` (50) and `ilostat_list_reference` (500) is applied as the cap with a notice and `next_cursor`; hard ceilings are 1,000 and 10,000 ([#22](https://github.com/cyanheads/ilostat-mcp-server/issues/22)).
- **`ilostat_search_indicators`** matches derived word forms by light suffix stemming when a term matches no indexed word, so `informality` finds `informal` ([#21](https://github.com/cyanheads/ilostat-mcp-server/issues/21)).
- **Breaking: `ilostat_compare_geographies`** in period mode with `change_years` echoes `time_from`/`time_to` in `applied_filters` where it populated `time`.
- **Breaking: `ilostat_dataframe_query`** refuses settings and file functions (`current_setting`, `current_schema`, `query_table`, and similar) through the framework SQL gate; the tool declares the gate's `sql_read_only` reason.
- **Framework** `@cyanheads/mcp-ts-core` ^0.13.15 adopted; framework skills, agent docs, and the framework anti-pattern scan are re-synced.

## Security

- **DataCanvas SQL** runs with DuckDB external access off, directories allow-listed, and configuration locked, inherited from `@cyanheads/mcp-ts-core` 0.13.15.
