# 0.1.1 — 2026-09-26

First published release. Reads two keyless ILO APIs: `rplumber.ilo.org` (catalog, code dictionaries, observations) and `sdmx.ilo.org` (breakdown codes, default slice, units). Every capability is a tool; there are no resources or prompts.

## Added

- **`ilostat_search_indicators`** — searches the indicator catalog by plain-language `query` plus `frequency`, `database`, `subject`, `breakdown`, and `aggregates_only` filters; one hit per indicator with a dataset ID per frequency, facets over the whole match set, up to 50 hits per `cursor` page.
- **`ilostat_describe_indicator`** — one dataset ID or bare indicator code: definition, unit and multiplier, frequency variants, the breakdown codes `ilostat_query_indicator` accepts (totals marked `is_total`), `default_slice`, covered areas, `basis_rule`, and related indicators. An unknown code returns `found: false`.
- **`ilostat_query_indicator`** — observations for 1–3 `dataset_ids`, filtered by `ref_areas` (up to 300), `area_group`, `sex`, `classif1`, `classif2`, `sources`, and `time`, `time_from` / `time_to`, or `latest_only`; `source_selection` is `best` (default), `all`, or `secondary`. Rows keep source, status, decoded notes, and `basis`.
- **`ilostat_get_country_profile`** — nine headline labour-market indicators for one `ref_area` and `sex`, each with its latest reported value and, separately, its latest non-projected ILO modelled estimate.
- **`ilostat_compare_geographies`** — one dataset and slice across `ref_areas` and/or an `area_group`, at a common `period` or each area's latest value within `lookback_years`; optional `change_years`, a `rank`, `missing` areas with a reason, and `comparability` flags.
- **`ilostat_list_reference`** — decodes 11 topics (`ref_areas`, `area_groups`, `databases`, `subjects`, `sexes`, `classifications`, `classification_types`, `sources`, `obs_status`, `notes`, `frequencies`) by `filter` or exact `codes`, up to 500 entries per page.
- **Dataframes** — a query or comparison past `ILOSTAT_PREVIEW_CHARS` stages in full as a DuckDB `df_<id>` table. `ilostat_dataframe_query` runs one read-only `SELECT` and can store its result with `register_as`; `ilostat_dataframe_describe` returns provenance, coverage, basis counts, and column schema; `ilostat_dataframe_drop` is off unless `ILOSTAT_DATAFRAME_DROP_ENABLED=true`. A tenant holds at most 1,000,000 staged rows in 100 dataframes.
- **`basis` on every value** — `reported`, `modelled_estimate`, or `projection`, with the projection cutoff taken from the ILO modelled-estimates edition; a modelled value never fills a missing reported one.
- **Configuration** — `ILOSTAT_CATALOG_REFRESH_HOURS` (default 6), `ILOSTAT_MAX_ROWS` (500000), `ILOSTAT_PREVIEW_CHARS` (40000), `ILOSTAT_CACHE_TTL_SECONDS` (900), `ILOSTAT_DATASET_TTL_SECONDS` (86400), `ILOSTAT_DATAFRAME_DROP_ENABLED` (false). `CANVAS_PROVIDER_TYPE` defaults to `duckdb`; `none` turns the three dataframe tools off. No API key.
- **Upstream pacing and cache** — 60 requests a minute to rplumber and 20 to SDMX; a 429 or challenge page fails as a retryable `upstream_busy` carrying `retryAfter`. Data responses of up to 5,000 rows are cached.
- **Transports and distribution** — stdio and Streamable HTTP (stateless sessions); npm `@cyanheads/ilostat-mcp-server`, MCP Registry `io.github.cyanheads/ilostat-mcp-server`, a multi-arch GHCR image, Claude Code and Codex plugin manifests, and a `.mcpb` bundle, which ships without the DuckDB binding, so its dataframe tools report an install hint.
