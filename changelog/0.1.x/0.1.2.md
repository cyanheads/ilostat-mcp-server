# 0.1.2 — 2026-10-03

## Changed

- **Request errors**, through `mcp-ts-core` 0.13.9–0.13.11, carry field-specific recovery guidance and a request ID on both response surfaces; declared recovery hints are filled automatically.
- **String inputs**, through `mcp-ts-core` 0.13.9, accept safe integers when their decimal text passes validation, including numeric indicator-search queries.
- **Dataframe scratch storage**, through `mcp-ts-core` 0.13.9, uses a private per-process directory with isolated canvas spills and shutdown cleanup; `CANVAS_TEMP_PATH` names its parent.
- **Container packaging** installs OpenTelemetry peers from the framework's declared ranges and removes unused musl bindings from the glibc images.
- **Development tooling** adopts framework lint, packaging, and tag checks, fixes tracked-secret and TODO scans, and runs CodeQL per language; framework guidance is synchronized through 0.13.11.

## Fixed

- **MCP Registry launch entries** use `npx` without ignored npm-script arguments, and the HTTP entry fixes `MCP_TRANSPORT_TYPE=http`; registry metadata and the README include the public hosted endpoint.
- **Claude Code configuration** forwards `CANVAS_PROVIDER_TYPE`, allowing the existing dataframe tools to be disabled through the plugin's settings.
