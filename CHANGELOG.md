# Changelog

All notable changes to this project. Each entry links to its full per-version file in [changelog/](changelog/).

## [0.2.0](changelog/0.2.x/0.2.0.md) — 2026-10-15 · ⚠️ Breaking · 🛡️ Security

Per-series latest values, bounded dataframe previews and dataset batches, baseline provenance and break flags in compare changes, derived-word search, and SQL hardening from mcp-ts-core 0.13.15. Breaking: the compare period-mode filter echo and the SQL gate's denied functions.

## [0.1.2](changelog/0.1.x/0.1.2.md) — 2026-10-03

Framework 0.13.11 adoption brings clearer request errors and private dataframe scratch storage, with corrected registry launches and updated container packaging.

## [0.1.1](changelog/0.1.x/0.1.1.md) — 2026-09-26

First published release: nine tools over the ILO's keyless ILOSTAT data and SDMX APIs for indicator search and description, observation queries, country profiles, area comparisons, code decoding, and SQL over staged dataframes, with every value marked reported, modelled estimate, or projection.
